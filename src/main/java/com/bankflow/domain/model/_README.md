# domain/model

Aqui entram as entidades e Value Objects do domínio: `Cliente`, `Conta`, `Transacao`,
`LimiteDiario`, etc. — puro Java, sem anotações de framework (nada de `@Entity`,
`@Service`...). As regras de negócio (fase 1 do roteiro) vivem aqui.

Este arquivo é só um marcador temporário; pode apagar assim que criar as classes.
